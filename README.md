# Qare 360 Website

Premium marketing homepage for Qare — professional research made accessible.

## Stack

- Vite + React 19 + TypeScript
- Tailwind CSS
- Iconify

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Structure

- `src/pages/Homepage.tsx` — page composition
- `src/components/home/` — homepage sections
- `src/data/` — services, cases, blueprints, trust, process content
- `docs/` — strategy and Phase 2 notes
- `wireframes/` — historical low-fi reference

The approved homepage structure is Version 1.0. Phase 2 is refinement only.
